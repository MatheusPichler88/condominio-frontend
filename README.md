# Condomínio Frontend

Painel web para gestão de condomínios, consumindo a API do backend. 
Inclui dashboard, login com autenticação via JWT (cookies) e páginas 
de gerenciamento para moradores, unidades, boletos, contratos, 
funcionários, fornecedores, visitantes e reservas.

## Tecnologias

**Frontend:** Next.js, React, TypeScript, Tailwind CSS, Axios

## Como Executar

### Pré-requisitos

- Node.js 18 ou superior
- Backend rodando (veja o repositório `condominio-backend`)

### Instalação

```bash
npm install
```

### Rodar em desenvolvimento

```bash
npm run dev
```

A aplicação estará disponível em `http://localhost:3001`.
